Get In Touch

MisrPrime was built end-to-end in Ruby on Rails with Hotwire Native — an e-commerce website and native mobile app (iOS/Android) sharing one Rails codebase. This was Noor's first mobile app build, using Hotwire Native to wrap the Rails-powered web experience into fast, native iOS and Android apps rather than maintaining separate native codebases.

Development process

The goal was to ship both a web storefront and native mobile apps without duplicating the checkout and catalog logic twice. Using Hotwire Native, the same Rails views and Turbo navigation power both the website and the native app shells.

Challenges & solutions

Shipping one Rails codebase to both the web and native app stores raised a few real questions that had to be solved along the way.

Challenges

Building web and native apps together brought its own set of constraints

  • Avoiding duplicate catalog & checkout logic across web and mobile
  • Getting native-feeling navigation without a separate native codebase
  • Keeping the Rails app fast on mobile connections

Solutions

Each challenge was addressed with a Rails-first, Hotwire-driven approach

  • Kept one Rails codebase powering both the site and the app views
  • Used Hotwire Native & Turbo for native-feeling transitions inside the app shell
  • Used Tailwind CSS/Bootstrap for a fast, responsive front end
